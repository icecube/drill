# drill
command-line simulation tool for IceCube/Upgrade hole drilling

expects (time interval, sec) (drill speed, m/sec) (water flow rate, gal/min) (water temp, C)

outputs (time, hr) (depth, m) (hose temp, C) (hole temp, C) (hole radius, m)

[reference paper](https://www.cambridge.org/core/journals/annals-of-glaciology/article/modeling-hole-size-lifetime-and-fuel-consumption-in-hotwater-ice-drilling/1A84578C91A5F3030650DCF7382CF9B9)
